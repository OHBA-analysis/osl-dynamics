User Guide
==========

The user guide describes the methods implemented in osl-dynamics: the M/EEG processing pipeline that produces parcel time courses, the generative models for dynamic brain networks and the tools for statistical significance testing.

New users should start with the :doc:`Getting Started <getting_started>` guide and then work through the :doc:`tutorials <tutorials>`, which show the methods applied to real data, with links to example scripts and workshop materials. The :doc:`FAQ <faq>` covers common questions about data preparation, model training and post-hoc analysis, and the :doc:`API reference <autoapi/index>` documents every class and function.
